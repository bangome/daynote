생성 확인 · Day 화면이 안 보일 때
본문의 @ 구간이 칩으로 바뀌는 것만으로는 부족합니다. 칩은 캐럿 바로 옆이라 ‘글자가 바뀌었다’ 정도로만 읽히고, 어느 날짜·어느 리스트에 들어갔는지는 안 보입니다. 그래서 툴바에 ‘이 노트의 항목 N’ 자리를 두고, 새 항목이 그 자리에서 한 줄로 솟아 2.5초 보였다가 개수로 접힙니다. 객체가 실제로 사는 곳(노트의 항목 모음)에 나타나는 것이라 토스트가 아닙니다. 다른 날짜면 같은 줄 오른쪽에 ‘10/8에 추가됨 · 보기’. 폰에서도 토스트 없이 가능하다고 판단했습니다.
