01
@ 팝업 → 키보드 위에 붙는 바
캐럿이 거의 항상 키보드 바로 위에 있으므로 캐럿을 따라가는 카드는 방금 쓴 글을 가립니다. 그래서 키보드 액세서리 자리(평소 툴바 자리)를 @ 바가 대신합니다. 두 줄은 세로로 다 보여 주고, 종류 전환은 다른 줄을 탭(엄지 영역), 만들기는 선택된 줄의 ‘만들기’ 버튼 또는 키보드 리턴키(이때만 ‘만들기’로 바뀜), 취소는 ×. 힌트 줄은 이 세 가지가 화면에 직접 보이므로 없앴습니다.
