목록 탭 · 리스트는 칩 행
‘할 일 / 즐겨찾기 / 태그’ 세그먼트는 그대로 두고, 할 일 아래에 리스트 칩 행을 둡니다. 데스크톱에서도 리스트는 목적지가 아니라 날짜를 가로지르는 할 일 뷰의 필터이므로 칩이 맞습니다. 칩 안 숫자가 데스크톱 사이드바 개수(할 일 17 · 업무 7)와 같은 값. 새 리스트는 칩 행 끝 ‘+ 리스트’, 이름·색 변경과 삭제는 칩 길게 누르기. 기본 리스트 메뉴에는 삭제 항목이 없습니다.
